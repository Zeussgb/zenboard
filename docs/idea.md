# ZenBoard — Idea del proyecto

## ¿Qué problema resuelve?
ZenBoard es una aplicación que combina un gestor de notas y un
gestor de tareas en un mismo sitio. El problema que resuelve es
tener que usar aplicaciones separadas para apuntar ideas y
gestionar tareas pendientes. Con ZenBoard todo está en un solo lugar.

---

## Usuario objetivo
Cualquier persona que necesite organizarse en su día a día:
estudiantes, desarrolladores, o cualquiera que quiera tener
sus notas y tareas bien organizadas.

---

## Funcionalidades principales

### Notas
- Crear notas con título y contenido
- Editar notas existentes
- Eliminar notas
- Buscar notas por título
- Organizar notas por categorías

### Tareas
- Crear tareas con título y descripción
- Editar tareas existentes
- Eliminar tareas
- Marcar tareas como completadas
- Buscar tareas por título
- Organizar tareas por categorías
- Añadir fecha límite a las tareas

---

## Funcionalidades opcionales
- Modo oscuro
- Filtrar tareas por estado (pendientes/completadas)
- Filtrar por fecha límite (vencidas, hoy, próximas)
- Ordenar notas y tareas por fecha de creación
- Contador de notas y tareas en el panel lateral

---

## Mejoras futuras
- Sistema de etiquetas además de categorías
- Notas con formato enriquecido (negrita, listas...)
- Exportar notas en PDF
- Sincronización entre dispositivos con base de datos real
