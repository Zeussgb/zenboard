# ZenBoard

Aplicación web fullstack para gestionar notas y tareas en un solo lugar.
Construida con React, TypeScript, Tailwind, Node.js y MySQL.

## Tecnologías
- Frontend: React + TypeScript + Tailwind CSS
- Backend: Node.js + Express
- Base de datos: MySQL
- Despliegue: Vercel
